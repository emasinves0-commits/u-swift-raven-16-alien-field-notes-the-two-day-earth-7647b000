# Alien Field Notes: The Two-Day Earth

An alien visitor files a hotel-style review of Earth after a two-day stay: five stars for the room, zero for the hosts — they waved goodbye at checkout, then followed the guest home in a metal tube for years. The abduction is reframed as a hospitality complaint, and the whole joke lands in a single clean line with the punch ("for years") at the very end.

## How it works

`main.ts` writes the entry line to `entry.txt` in the output directory (default `/output`, overridable with `MAKEFUN_OUTPUT_DIR`).

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

This produces `out/entry.txt` containing exactly the entry text — 117 bytes, no trailing newline.
